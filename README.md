# Vacancy Analyzer
This project collects and analyzes job vacancy data from different sources.
It helps identify in-demand skills, trends, and salary levels.

## Features
- Scrapes job data from selected websites
- Stores data in a database or local files
- Generates analytics reports

## Tech Stack
- Python
- Pandas
- BeautifulSoup or Selenium
- Matplotlib / Plotly
